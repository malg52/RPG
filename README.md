# Console RPG Battle Game (C#)

## Description
Console-based RPG game with turn-based combat between player and enemy.

## Features
- Player vs Enemy battle system
- Turn-based mechanics
- Attack, heal and dodge abilities
- Cooldown system for abilities
- Difficulty levels (easy, medium, hard)
- Customizable game settings
- Random enemy behavior (AI)

## Technologies
- C#
- .NET (Console Application)

## Notes
- Focus on OOP (classes, inheritance, polymorphism)
- Includes basic AI logic for enemy decisions
